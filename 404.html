02 File to PDF: my true first app

See my first prototype turn a file into a PDF.

Was there an earlier version?

File the PDF was my first app built with AI coding help, while I was trying Claude, an AI assistant. The goal: convert files without a conversion website or subscription, or relying on the Mac’s Preview app.

It was simple, but it taught me how to build PDF conversion into another app. I later reused that work here.

04 The actual app

A closer look at the Mac app that grew from this idea.

What was the hardest part?

There wasn’t an easy way for the app to request files directly from Brightspace. I leaned on web scraping, reading the website’s pages to find the files.

I added checks so the app didn’t have to scan everything again on each run. It took me back to graduate-school algorithms: how do you read through a linked list, a chain of connected items, as quickly as possible?

What detail are you proud of?

The interface is my least refined, but it solved a real problem: my class files were there when I needed them. It pushed me to keep studying everyday design.

It also made me think about electronic medical records: useful tools can still need a better interface.

Mac app / Course files

Course files downloaded, organized on your Mac

More time working with the material. Less time finding it.

Before you watch: a quick glossary

Brightspace
A learning management website (LMS) where professors post courses and store class files. This is the file repository—the source—that the app copies from.
Sync
Keep a matching copy of those files and folders in one place on your Mac. It mirrors Brightspace one for one in your file browser. That folder can also live in cloud storage for access across devices.

AssessWhat was getting in the way?

Log in, open the class, find the section, download the file. Each trip was small, but they added up. I kept downloading fresh copies because I wasn’t sure what had changed.

IdentifyWhat needed to change?

Even with my software background, I was still hunting for files. I wanted class materials organized on my computer, with cloud storage making them available across my devices.

PlanWhat was the strategy?

I thought of it as an appliance: one function, done well. A dedicated Mac app would collect class files, flag new material, and give folders and filenames a consistent structure.

BuildWhat did you make?

I built Brightspace Sync mostly on my own. It tracks files that are new, updated, or removed, with a history of changes. Handling unusual filenames took extra care. Making the interface feel cohesive was harder than I expected.

EvaluateWhat did you learn?

Before I could study the material, I had to find it. The files were there when I needed them, but I learned how much iteration good design takes. Next, I’d like to simplify the interface, test it with other students, and work toward a Mac App Store release.
