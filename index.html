02 / Goals

Where time
is saved.

Three workflow reductions lead to one outcome: more time to study.

01

Access files

Course information is spread across Brightspace folders and file formats.

Bring current files and PDFs into one organized local folder.

Reduce formatting time

Move existing information into the required forms so the written work starts sooner.

Reduce input time

Reuse saved routine selections, then enter and review case-specific information manually.

Study time

File handling, formatting, and repeated entry consume study time.

Information / Course files

Brightspace Sync

Mac app + landing page
Interface previewMac app + landing page
Problem

Course files are spread across Brightspace folders and formats, with repeated downloading and conversion.

Solution

One update pulls current course content into a local folder, skips unchanged files, and makes missing PDFs.

Workflow / Clinical documentation

Concept Map Builder

Live web app
Interface previewLive web app
Problem

The same case information has to be moved into a rigid concept-map PDF, then reformatted field by field.

Solution

Upload a Typhon case log. The app fills a draft, marks missing or uncertain fields, and exports the reviewed map.

04
Workflow / Repeated input

Typhon Form Filler

Core prototype
Interface previewCore prototype
Problem

Typhon requires the same routine selections across long clinical-log forms.

Solution

The extension applies the user's saved routine selections to matching fields. It does not generate information; it only makes repeated input faster.
