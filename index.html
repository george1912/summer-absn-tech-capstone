03 / Time saved

Recurring tasks.
Specific goals.

The goal is simple: spend less time moving and formatting information.

01

Typhon input

Repeated selections in long clinical-log forms.

Reduce routine data entry while keeping case details visible for review.
02

Concept Map + Critical Points

Required information has to be reformatted into rigid documents.

Save time formatting documents so the written work can begin sooner.
03

File Sync

Course information is spread across folders and file formats.

Collect and organize course information in one dependable local folder.

Saved time made room for study tools. The next step was connecting each tool to a clear page where it can be opened directly.
