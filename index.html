FIELD NOTE 01Mac application · Course files

Project 1 of 7

Brightspace Sync

Make the workspace ready before the studying begins.

01 Problem

Reaching one course file meant signing in, finding the course, opening content, locating the module, downloading the file, and organizing it before any learning could begin.

02 Observation

The sequence repeated across courses and devices. Files were easy to lose, difficult to keep current, and sometimes remained in formats that were harder to read or annotate.

01
BUILD LOGMETHOD + REFLECTION

03 Inspiration

File-transfer protocols suggested a central repository. Cloud storage showed how material could remain available across devices. An earlier PDF converter suggested preserving the original while preparing a more useful copy.

04 How I built it

A standalone Mac app synchronizes current course files locally, records what it has already seen, and creates a missing PDF copy when useful.

05 What I learned

The surface problem was too many clicks. The deeper problem was readiness: a good workflow tool prepares the environment without deciding what the learner should think.
